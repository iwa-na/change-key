# 軽騎兵 移調プレイヤー

スッペ「軽騎兵」序曲の録音を、テンポを変えずに好きなキーで再生するウェブアプリです。

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開している場合はそのページを開く）。
2. 録音ファイル（MP3 / OGG / WAV など）を選ぶか、画面にドロップする。
   - オーケストラ録音の例：[IMSLP](https://imslp.org/wiki/Leichte_Kavallerie_(Supp%C3%A9%2C_Franz_von)) の Schüchter 指揮盤
3. 「再生したい調」を選んで再生する。基準は主部ギャロップのイ長調。

ファイルはブラウザ内だけで処理し、どこにも送信しません。録音ファイルはこのリポジトリには含めていません。

## 機能

- 12 の調への移調（方向は「近い方」「上げる」「下げる」から選択）
- セント単位の微調整（録音のピッチが A=440Hz からずれている場合用）
- テンポ変更（50〜150%）、音量、再生位置の変更
- スペースキーで再生／一時停止

## 使用ライブラリ

- [SoundTouchJS](https://github.com/cutterbl/SoundTouchJS) 0.1.30（LGPL-2.1）— unpkg から読み込み
